## 📦 What is in this Repository?
This repository is the dedicated public documentation and marketing hub for **Meter Record**:
* **`index.html`** / **`USER_GUIDE.md`**: Complete step-by-step user manual with workflows, tips, and FAQ.
* **`media-kit/`**: High-resolution screenshots, Google Play feature graphic banner, fact sheet, and press releases.
* **`media-kit/STORE_LISTING.md`**: Official Google Play Store listing text (English & Urdu).
* **`media-kit/PRESS_RELEASE.md`**: Press release for tech media and publications.
* **`media-kit/SOCIAL_MEDIA_KIT.md`**: Launch threads and WhatsApp broadcast templates.

*(Note: The Android application source code is maintained separately in a private repository. App releases are distributed via Firebase App Distribution and Google Play).*
